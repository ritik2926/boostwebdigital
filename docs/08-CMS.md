# CMS

Not yet implemented — later phase (see [10-ROADMAP.md](10-ROADMAP.md)).

## Plan

WordPress as a **headless CMS** on Hostinger, connected to the Next.js frontend via REST API (WPGraphQL/REST). Editors (non-technical) manage content there; developers never hand-edit content.

Content types to support:

- Blog posts
- Service pages
- Categories
- Authors
- Metadata (SEO fields per entry)
- Redirects
- Featured images

Design the CMS schema for a non-technical editor first — field names and structure should read clearly to Ritik or a future content hire, not just to a developer.
